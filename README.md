# primordial-soup · 原始汤

中文 | [English](README.en.md)

**首个撞击式记忆系统：不检索旧想法，随机撞出新东西。**

> 跨对话联想机制：对话沉淀"氨基酸卡"，新会话"闪电"随机碰撞旧卡。

> **定位：已知公开项目中，尚未发现同类的四层组合。** 记忆类项目的主流路线是「检索」或「压缩」——本机制的核心动作是「**碰撞**」：随机翻出旧卡撞向今天的话题，靠意外连接产生新东西。截至 2026-08 调研，公开近亲（[A-MEM](https://github.com/amemhq/amem) 系＝图链接+语义检索+LLM 驱动进化；memory-compiler 系＝摘要+嵌入检索压缩）均未覆盖「真随机抽样（含野卡槽）× 权重演化（赫布/蔡格尼克/遗忘）× 蛋白质合成 × 全量台账审计」四层。检索记忆的项目很多，**撞记忆的项目几乎没有**。

| 路线 | 代表 | 访问记忆的方式 | 本机制的不同 |
|---|---|---|---|
| 语义检索进化 | A-MEM 系 | 按相关度排序取回 | 抽卡靠**加权随机**不靠相关度——意外是特性不是缺陷，刻意挑选会杀死意外连接 |
| 摘要/嵌入压缩 | memory-compiler 系 | 压进上下文窗口 | 记忆**不进上下文**，只在碰撞命中且通过呈现闸门时出现，否则完全静默 |
| 跨对话联想（本项目） | primordial-soup | 随机碰撞 + 裁定演化 | 四层组合：真随机（野卡保底意外）× 权重演化 × 蛋白质合成 × 全量审计（沉默也要登记） |

原始汤（primordial soup，取自生命起源的隐喻）是一个把记忆落在文件夹里的联想系统：每次对话的结论结晶成一颗「氨基酸」卡，新会话开始时一道「闪电」——米勒实验式的随机碰撞——从旧卡里随机抽出几颗撞向今天的话题，撞出的火花可能修正旧结论、回答旧问题、或合成新的「蛋白质」综述。全部记忆在文件系统里，不依赖任何全局记忆。

- 氨基酸 ＝ 一次讨论的结论卡（一条强结论一行，含未解问题与可连接点）
- 蛋白质 ＝ 多张卡合成的综述（入池参与闪电，但与其成员卡不同出）
- 闪电 ＝ 加权随机抽样（2 加权 + 1 野卡），把旧卡撞向今天的话题
- 潮汐 ＝ 每周一次的对账任务：清欠裁定、簇检测、结案提案（只提议不实施）

## 特性

- **真随机碰撞**：选卡由抽样器用系统熵（或 `--seed` 复现）确定性计算，模型禁止自行挑卡——刻意挑选会杀死意外连接。
- **增量呈现闸门**：碰撞产物必须通过四条增量判据之一才呈现（改变结论 / 反例张力 / 回答旧问题 / 开出新方向），否则完全静默，不留仪式性痕迹。
- **沉默可审计**：被静默的抽取同样登记台账，静默率进入 M5 有效性结算，闸门松紧可量化。
- **裁定权在用户**：AI 只提案，用户一题一卡四档裁定（强认可/认可/无感/反对）；强认可触发赫布 ×2 权重。
- **权重脚本算，模型禁裁量**：赫布学习、蔡格尼克保温、遗忘衰减全部由脚本确定性计算。
- **只追加、不改写**：编号永不变更，双向回写只追加标注——引用过旧号的文本永远不会指错卡。
- **宿主无关**：机制规范与脚本是纯文件+命令行；对具体宿主（如 DSH）的适配独立成层，见 `adapters/`。

## 五分钟上手

见 [`examples/GETTING-STARTED.md`](examples/GETTING-STARTED.md)：复制合成样例汤 → 闪电 → 沉淀 → 状态页，全程合成数据，两分钟跑通全链路。

## 脚本参数速查

| 脚本 | 参数 | 说明 |
|---|---|---|
| 闪电抽样器.py | `root`（必填） | 汤根绝对路径；只读，零副作用 |
| | `--exclude 文件夹名` | 抽样前移除，可多次（精确→前缀无关→子串唯一三级匹配） |
| | `--seed 整数` | 随机种子；不给则系统熵（打印复现命令） |
| | `--n 整数` | 抽取数，默认 3（2 加权 + 1 野卡） |
| | `--hebb / --zeig-closed / --decay / --floor / --min-rows` | 权重参数 CLI 化（默认 2.0 / 0.5 / 0.7 / 0.1 / 10） |
| | `--strict` | 校验 INDEX 行数 == 磁盘卡文件夹数 |
| 状态页生成器.py | `root`（必填） | 默认输出 `<root>\_氨基酸库\状态页.html` |
| | `--stamp` | 固定时间戳（`"YYYY-MM-DD HH:MM"` 或 `fixed`）；缺省＝now |
| M5结算脚本.py | `root`（必填） | 复用抽样器解析段做结算（spawn 失败/9009/空输出明确报错） |
| | `--sampler 路径` | 显式指定抽样器（默认 `<root>\_氨基酸库\闪电抽样器.py`） |
| 潮汐周报生成器.py | `<周报md路径> [输出html路径]` | 字段行须 `- 【label】text`；退出码 3＝对账缺失 |

权重合成公式结构、呈现闸门四条增量判据、静默可审计、双向回写只追加，是机制本体，未参数化。

## 设计原则

1. **真随机**：随机性只由抽样器承担（系统熵或 `--seed` 复现），模型不得自行挑卡。
2. **呈现闸门**：增量检验不过就完全静默——不呈现、不解释、不留仪式痕迹。
3. **沉默可审计**：静默的抽取照常登记，静默率进 M5 结算，闸门松紧可量化校准。
4. **裁定权在用户**：AI 的推荐只是提案，点击才是裁定；强认可须指认具体位置（结构判据，禁强度形容词）。
5. **权重脚本算，模型禁裁量**：赫布 ×2 / 蔡格尼克保温 / 遗忘衰减全部脚本确定性计算。

## 适配层

机制规范与脚本宿主无关；对具体宿主（agent 运行时/工作区约定/交互工具/定时机制）的适配放在 `adapters/`：

- `adapters/ds-harness/` —— 面向 DSH 宿主：`SKILL.md`（技能全文）、`INSTALL.md`（安放位/热重载/脚本分发两模式）、`PORTING-NOTES.md`（移植清单与设计笔记合并稿：依赖映射、脚本层发现、契约基线、改造工单 R1-R7）。

## 从哪来

本项目机制脚本经私有部署环境测试后开源；公开仓库内不含任何私有数据，样例汤（`examples/mini-soup/`）全部为合成虚构数据。
