# 五分钟玩转原始汤

开箱演示：建汤 → 闪电 → 沉淀 → 状态页。全程只用本仓库的合成样例（`examples/mini-soup/`）与四个脚本，不碰任何真实数据。

前置：本机装有 Python 3（Windows 上用 `py`；Linux/macOS 上用 `python3`，下文以 `py` 代指探测到的解释器）。

## 第 0 步：复制样例汤（30 秒）

先把样例汤复制到你自己的工作区，后面所有命令都对着副本跑，避免改动仓库里的样例：

```powershell
# Windows（pwsh）
Copy-Item "examples\mini-soup" "<你的工作区>\my-soup" -Recurse
```

```bash
# Linux/macOS
cp -r examples/mini-soup <你的工作区>/my-soup
```

样例汤长这样（这就是原始汤的文件夹契约）：

```
my-soup\
  _氨基酸库\            # 机制核心：登记表、台账、模板、周报
    INDEX.md             # 全部氨基酸的登记表（范围守卫判据：存在它才算原始汤）
    闪电台账.md          # 每次闪电抽取与裁定的登记
    产品台账.md          # 产出物三表视图
    氨基酸模板.md        # 写卡模板
    蛋白质：测试簇.md    # 一张蛋白质（多卡合成综述）
    潮汐周报\            # 潮汐周报存放处
  <对话文件夹>\_氨基酸.md   # 每颗氨基酸一张卡
```

## 第 1 步：闪电（随机碰撞，30 秒）

模拟"新会话开始"：对样例汤跑一次加权抽样（2 颗加权 + 1 颗野卡）：

```powershell
py scripts\闪电抽样器.py <你的工作区>\my-soup --seed 1
```

- `--seed` 指定随机种子，同 seed 输出逐字节一致（可复现）；不给则用系统熵。
- 权重由脚本按台账确定性计算（赫布认可 ×2 / 蔡格尼克保温 / 遗忘衰减），**模型只解读，不心算、不挑卡**。
- `--exclude 文件夹名` 可在话题延续某旧卡时排除它；`--n` 改抽取数；`--strict` 校验 INDEX 行数与磁盘卡文件夹数一致。

## 第 2 步：沉淀（写卡归档，1 分钟）

结束一个话题时，给对话文件夹落一颗氨基酸。参照 `_氨基酸库/氨基酸模板.md`：

```markdown
## 编号
A-007

## 主题
（一句话主题）

## 标签
#机制设计 #联想机制 @统计学

## 核心结论
- （强观点，最多 3 条，不写过程）

## 未解问题
- （留给未来闪电的燃料，认真写）

## 可连接点
- （允许大胆猜测）
```

然后在 `_氨基酸库/INDEX.md` 表格末尾追加一行（编号＝末行编号加一，号一经发出永不变），并在 `_氨基酸库/闪电台账.md` 按规范句式登记本次抽取（先碰撞后登记，被静默的抽取也要登记——沉默可审计）。

## 第 3 步：状态页（30 秒）

沉淀后重建状态仪表盘：

```powershell
py scripts\状态页生成器.py <你的工作区>\my-soup --stamp fixed
```

- 生成 `_氨基酸库/状态页.html`，浏览器打开即可查看（数据预生成嵌入静态页，刷新即最新）。
- `--stamp "YYYY-MM-DD HH:MM"` 固定时间戳用于确定性重建；缺省＝当前时间。

## 第 4 步（可选）：M5 有效性结算 与 潮汐周报

```powershell
# 有效性结算（复用抽样器解析段，指标：未解问题关闭数 / 强认可计数 / 静默率）
py scripts\M5结算脚本.py <你的工作区>\my-soup --sampler scripts\闪电抽样器.py

# 潮汐周报 → HTML（周报字段行须 `- 【label】text` 形式；退出码 3＝对账缺失）
py scripts\潮汐周报生成器.py <你的工作区>\my-soup\_氨基酸库\潮汐周报\潮汐-2026-08-17.md <你的工作区>\my-soup\_氨基酸库\潮汐周报\潮汐-2026-08-17.html
```

M5 默认在 `<汤根>\_氨基酸库\` 下找抽样器（模式 A 分发）；脚本与汤根分离部署（模式 B）时用 `--sampler` 显式指路。

## 从零建汤（不复制样例时）

建一个文件夹，里面只放三样东西就能被范围守卫识别为原始汤：

1. `_氨基酸库\INDEX.md`：至少一行表头
   ```markdown
   | 编号 | 日期 | 文件夹 | 主题 | 标签 | 一句话结论 |
   |:----:|------|--------|------|------|-----------|
   ```
2. `_氨基酸库\闪电台账.md`：
   ```markdown
   | 日期 | 会话 | 抽中氨基酸 | 是否呈现 | 用户裁定 | 备注 |
   ```
3. 至少一个 `<对话文件夹>\_氨基酸.md`（内容按模板）。

随后即可跑闪电；抽样器在台账数据行 <10 时自动退化为均匀抽样，等池子养大后自动启用加权。

## 机制速记

- 范围守卫：根目录存在 `_氨基酸库/INDEX.md` 才算原始汤，其他项目一律不建库。
- 呈现闸门：碰撞产物过不了"增量检验"就完全静默，不呈现、不仪式性声明。
- 裁定权在用户：AI 只提案（选项说明里的推荐），点击才是裁定；裁定回填台账四档（强认可/认可/无感/反对）。
- 完整规则见 `spec/SOUP-MECHANISM.md`；宿主部署（如 DSH）见 `adapters/`。
